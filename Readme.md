# программа вывода метаданных медиафайла.
используется библиотека ffmpeg.
программа компилируется и используется на OS Linux (x86).


### 1. ПОДГОТОВКА К ИСПОЛЬЗОВАНИЮ 
требуется предварительная установка библиотек:
  libavcodec, libavformat


### 2. СБОРКА 
сборка программы (исполняемого файла):

** компиляция программы. исполняемый файл будет помещен в папку bin/
> make

** очистка. удаление папки bin/ (со всем содержимым)
> make clean

** компиляция для проверки на корректность работы с памятью.
> make DEBUG=1  
** далее запуск программы (см ниже).  
** после проверки удалить программу (> make clean) и собрать заново без DEBUG=1 (> make)


### 3. ИСПОЛЬЗОВАНИЕ 
программа запускается из командной строки (CLI).
программа принимает 1 обязательный аргумент - имя медиафайла.

пример запуска программы:
> ./app my_video.mp4

программа показывает:
* количество потоков;
* типы аудио/видео кодеков потоков;
* количество кадров;
* длительность файла по времени.
