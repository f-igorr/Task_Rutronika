

Задание:

1.Создать новое приложение на чистом c++ языке.

2. Подключить библиотеку ffmpeg

3. Приложение должно запускаться и выводить данные указанного произвольного видеофайла при помощи подключенной библиотеки:

- количество потоков

- типы аудио/видео кодеков потоков

- количество кадров

- длительность файла по времени

Имя и путь файла указывается через командную строку при запуске приложения.

Написать и оформить инструкцию по сборке и запуску проекта в Readme.md и загрузить проект в репозиторий git.

Программа должна компилироваться и запускаться на ОС Linux
